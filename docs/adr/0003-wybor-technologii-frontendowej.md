# 3\. wybor technologii frontendowej

Date: 2026-08-05

## Status

Proposed

## Kontekst

Aplikacja wymaga stworzenia interfejsu użytkownika umożliwiającego komunikację z backendowym API, obsługę formularzy oraz nawigacji. Wybrana technologia powinna wspierać tworzenie rozbudowanej aplikacji oraz zapewniać czytelną strukturę projektu.

## Decyzja

Frontend aplikacji zostanie zaimplementowany z wykorzystaniem frameworka Angular oraz języka TypeScript.

## Konsekwencje

Typescript w przeciwieństwie do JavaScript oferuje silne typowanie danych co zmniejsza ryzyko wystąpienia błędów.

Ze względu na wybór Typescript jako języka do frontendu w aplikacji będziemy wykorzystywać inne języki programowania dla frontendu i backendu.

## Alternatywy

React



Zaleta: duża popularność i duża ilość bibliotek.

Wada: wymaga samodzielnego wyboru wielu dodatkowych narzędzi, na przykład do routingu i zarządzania stanem.



Blazor



Zaleta: umożliwia tworzenie frontendu w języku C# i ułatwia współdzielenie modeli z backendem .NET.

Wada: mniej rozbudowany framework w porównaniu do typescripta oraz brak znajomości tego narzędzia.



Vue.js



Zaleta: ekosystem zajmuje zdecydowanie mniej miejsca.

Wada: framework ze względu na fakt, że jest nowszy nie jest jeszcze tak rozbudowany jak Angular.
