Tytuł: Użycie ASP.NET jako frameworku odpowiedzialnego za backend
Status: Proposed
Kontekst: Projekt opiera się o interakcje systemu z bazą danych więc kluczowym jest wybranie odpowiedniego sposobu komunikacji serwer <-> baza danych
Decyzja: Wybrany został ASP.NET ze względu na wydajność, stabilność oraz komfort pracy
Konsekwencje: Backend będzie musiał być napisany w języku C#; Backend oraz Frontend będą napisane w innych językach programowania
Alternatywy: Java + Hibernate + SpringBoot, Javascript + Express.js
