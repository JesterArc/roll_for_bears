Tytuł: Użycie PostgreSQL jako głównej bazy danych
Status: Proposed
Kontekst: Projekt opiera się o interakcje systemu z bazą danych więc kluczowym jest wybranie odpowiedniego rodzaju technologii
Decyzja: Wybrana została baza PostgreSQL, ze względu na najlepsze wsparcie formatu .JSON
Konsekwencje: Struktura przetrzymywania danych zostanie narzucona przez postreSQL
Alternatywy: MsSqlServer, MongoDB
