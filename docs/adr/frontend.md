Tytuł: Użycie Angular jako frameworku odpowiedzialnego za frontend
Status: Proposed
Kontekst: Projekt opiera się o interakcje systemu z bazą danych więc kluczowym jest wybranie odpowiedniego narzędzia umożliwiającego użytkownikowi na wygodną interakcję z systemem
Decyzja: Wybrany został Angular, gdyż jest napisany w języku TypeScript, który jest stałotypowany, co zapewnia większe bezpieczeństwo kodu
Konsekwencje: Frontend będzie musiał być napisany w języku TypeScript; Backend oraz Frontend będą napisane w innych językach programowania
Alternatywy: Javascript + React; Java + Swing; Java + JavaFx
